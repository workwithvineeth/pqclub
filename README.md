# PQ Club (test app)

The test version of PICKLEQ with Club mode, published at **https://workwithvineeth.github.io/pqclub/**.

- The code is in [workwithvineeth/pickleq](https://github.com/workwithvineeth/pickleq), branch `club-mode`. This repository holds no app code; its workflow builds that branch and publishes it here.
- It has its own address so that on Android it installs as its own app, separate from PICKLEQ at /pickleq/.
- Temporary: at launch Club mode moves into PICKLEQ itself and this repository can be deleted.
